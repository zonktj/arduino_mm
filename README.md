This is code for Arduino UNO (R3, but will work on R4) to control a Mosquito Magnet.

The hardware setup is:

Mainboard: Arduino UNO R3
Remote on/off: Shelley Plus Uni Smart WiFi
Relay module: Luxorparts relay for Arduino 4x
Voltage regulator: LM2592s (in 12V, out 5V)
Powered by a 12V car battery or similar

Schematics will be added later

Tempsensor code is just for trying out the voltage levels from thermistor given different temperatures.
Used only to get proper thresh hold values for the main code (and is not used at all)

Use V3 code which includes the original tempsensor and proper security procedures.
